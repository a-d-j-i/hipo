hipo

Local-first mortgage loan tracker and the framework it's built on.

Live demos

  • hipo — the full product (parties, loans, payments, payouts, audit log).

    Runs entirely in your browser. SQLite-WASM + OPFS persists data locally; back up to a folder, GitHub repo, or the vault server.

  • templates/minimal — the framework's smallest working consumer.

    Bootstrap → setup → "hello, <user>" with backup & restore. The build gate: any packages/* change that breaks this is wrong by construction.

Desktop installers

Tagged versions ship via GitHub Releases. Auto-updater feed: github.com/CHANGE_ME_OWNER/CHANGE_ME_REPO/releases/latest/download/latest.json.

Linux users: this Pages site is the documented Linux entry point (webkit2gtk lacks the OPFS sync handle the Tauri shape needs; Phase 12's native-SQLite path will revive Linux Tauri).

Signing key

Updater bundles are signed with the Tauri ed25519 key. Fingerprint published alongside the first release. Verify before installing.
